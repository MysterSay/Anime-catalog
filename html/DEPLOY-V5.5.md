# Yoru v5.5

## Зміни
- Пошук групи на сторінці тайтлу + фіксована висота dropdown зі скролом.
- Сортування каталогів: зелені -> без кольору -> червоні.
- Повноекранне редагування тайтлу без входу в Notion.
- Редагування назв, аліасів, статусу, групи, опису, постера, банера, вибраного/улюбленого.
- Завантаження локальних файлів постера/банера через Notion File Upload API.
- Редактор усіх каталогів, включно з порожніми; додавання/видалення посилань.
- API для розширення: `/api/extension/context` шукає існуючий тайтл у полі `Аліаси` та повертає групи/статуси.

## Deploy
```powershell
npx --yes wrangler@4.120.0 pages deploy . --project-name myster-anime
```

## Перевірка
```powershell
Invoke-RestMethod "https://myster-anime.pages.dev/api/version" | ConvertTo-Json -Depth 10
```
Очікувана версія: `yoru-v5.5-editor-extension-2026-08-13`.
